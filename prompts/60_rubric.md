# 出图自检 Rubric (prompts/60_rubric.md)

> 适用：绘图代码生成后与渲染产物导出前的可执行判定检查项
> 与代码的对应：`academic_fig.checks`, `academic_fig.export`, `academic_fig.cli`

---

本 Rubric 包含 14 项严格可执行、可判定、可度量的自检规则。每一条都配备了明确的判定方法与失败特征。出图交付前必须 100% 通过：

| 规则 ID | 检查项 | 判定方法 (可执行 / 可度量) | 失败示例 (长什么样) |
|---|---|---|---|
| **R-01** | **字体缺失与乱码检查** | 静态检查代码字符串是否含中文与 `$` 混排；运行渲染时捕获 stderr，检查是否有 `does not have a glyph`。行数必须严格为 0。 | 中文文字处出现白色方块（`ToFu` 空白框），文字无法阅读。 |
| **R-02** | **数学公式与中文混排隔离** | 正则检测图内所有 text 字符串，凡同时出现中文字符（`[\u4e00-\u9fa5]`）与 `$` 公式符号的判定为不合格。 | `时间 $t$ / s` 导致“时间”两个字在 Matplotlib 中缺失变成方块。 |
| **R-03** | **物理尺寸与栏宽规范** | 检查输出 figure 的宽度尺寸：单栏图必须为 `3.35 ± 0.1` 英寸，双栏图必须为 `7.0 ± 0.2` 英寸。 | 随意指定 `figsize=(12, 8)`，插入 Word 或 LaTeX 单栏时被缩放到字迹模糊。 |
| **R-04** | **长宽比合规度** | 计算最终导出图的宽高比（宽 / 高）：必须严格落在 `[0.60, 2.60]` 区间内。 | 宽高比为 3.2 的细窄长条图，或者宽高比 0.4 的细高柱，版面严重畸变。 |
| **R-05** | **网格线纯净度** | 检查 `ax.grid` 状态：必须为关闭状态；若启用，其参数必须满足 `lw <= 0.6` 且 `alpha <= 0.15`。 | 坐标轴背景满布深灰色粗重实线方格，比数据点还抢眼。 |
| **R-06** | **图例位置与遮挡碰撞** | 反算图例的 BoundingBox 与数据关键点/极值点坐标：重叠点数必须为 0；必须设 `frameon=False`。 | 一个带黑边框的大图例框直接压住了两条核心折线的交叉拐点。 |
| **R-07** | **颜色冗余编码 (灰度可辨)** | 转换图像至灰度图（Luminance），比较不同数据序列在灰度下的对比度差值，明度差必须 `>= 12%`；同时检查曲线是否配置不同 Marker 或 Linestyle。 | 三条实线只改了红绿蓝，黑白打印后变成三条一模一样的灰色实线。 |
| **R-08** | **数据点数值过度标注** | 统计单个坐标区内通过 `ax.text` 标注的浮点数字数量：数据点总数 > 10 时，标注数字数量必须 `<= 2`（仅极值点）。 | 每个采样点头上都悬浮着一个 `92.4`、`87.1` 的小数字，密密麻麻重叠成黑色色块。 |
| **R-09** | **自设参考线与口径声明** | 凡调用了 `ax.axhline` 或 `ax.axvline` 绘制参考线，检查 `afg.footnote()` 文本内是否包含“自设目标”或“来源”关键词。 | 画了一条红虚线写着“目标门限”，但图注未解释该门限是国家标准还是本文作者拍脑袋定的。 |
| **R-10** | **示意性真值标注** | 凡图元 label 包含“真值”或“目标中心”，检查是否带有“（示意）”后缀，且图注写明“示意，非真实值”。 | 在传感器未测得的盲区画了一个实心红星当作真实位置却不声明是示意。 |
| **R-11** | **色图连续性与合规性** | 扫描 `imshow`、`contourf`、`pcolormesh` 调用的 cmap 参数：绝对禁止包含 `jet`、`rainbow`、`turbo`、`hsv`，必须为 `academic_fig.palette` 导出色图。 | 呈现温度场时使用刺眼的蓝绿黄红 Rainbow 渐变，在黄色过渡区形成虚假梯级跳变。 |
| **R-12** | **字号层级一致性** | 检查图内所有文本图元的字号设定：子图标题必须为 `11pt`（不加粗），轴标签必须为 `10pt`，刻度与图例必须为 `9pt`，图注必须为 `8.5pt`。 | 标题 16pt 粗体，轴标签 8pt，图例 12pt，字号混乱失调。 |
| **R-13** | **框架图文字溢出 (Box Overflow)** | 调用 `checks.check_box_overflow()`，验证所有模块内的文本 BoundingBox 是否完全内切于模块几何外框。 | 模块内部文字“多模态自适应融合网络”过长，字末两个汉字穿透了圆角矩形右边框。 |
| **R-14** | **矢量导出与字体嵌入** | 检查导出文件：必须同时包含 300 DPI PNG 与 PDF；PDF 必须保留可编辑文字（`pdf.fonttype = 42`，Type 42 TrueType 嵌入）。 | 仅导出一张压缩失真的手机截图 PNG，或者 PDF 里的文字全被转成了不可选中的矢量路径。 |

---

## 2. 自动化判定执行示例

在持续集成或构建自检脚本中，直接调用 CLI 执行如下判定：

```bash
python -m academic_fig.cli check --dir examples/out --strict
```

当退出码为 0 时方可交付；任一 Rubric 项违背均会输出错误 ID 及具体违规图表路径。

> 与代码的对应：`academic_fig.checks.check_dir`, `academic_fig.cli`
