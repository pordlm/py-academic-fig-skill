# 流程与泳道图设计规范 (prompts/40_diagram_flow.md)

> 适用：控制时序逻辑、多实体协作泳道、算法循环决策与状态转移
> 渲染器 API：`afg.diagrams.flow(spec, *, width='double', height=None, note=None, strict=True)`

---

## 0. 何时用这一篇

用：表达跨模块交互协同、时间步进时序、条件分支与循环状态机（如客户端-边缘-云端泳道图、控制决策状态机）。
不用：若展示静态静态层次结构与模块包含关系改用 40_diagram_architecture.md；若表达数据连续统计流动流向改用 30_cat_flow.md。
边界：泳道必须有清晰的实体表头与浅灰分界虚线；判定菱形必须明确标注 Yes/No 分支出口，箭头严禁从上方反向倒灌入上游节点。

## 1. 成员图型表

- 当展示跨多模块、跨多实体（如客户端与服务端、感知与执行器）的时序交互时。
- 当展示带有条件判断、循环迭代与重试机制的完整算法控制流时。
- 泳道数通常为 2~4 个；流程主线步骤控制在 4~8 步。

---

## 2. 核心代码骨架

```text
  [泳道 1: 云端调度器]         [泳道 2: 边缘执行端]
  ┌───────────────────────┐   ┌───────────────────────┐
  │ [任务分解与指派]       │   │                       │
  │ [WASH, INK 0.8pt]     │   │                       │
  └───────────┬───────────┘   │                       │
              │ 跨泳道箭头     │                       │
              └───────────────┼──────────────►┐       │
                              │ ┌─────────────▼─────┐ │
                              │ │ [状态校验与执行]  │ │
                              │ └─────────────┬─────┘ │
```

---

## 3. 必须做

1. **渲染器优先**：首选 `afg.diagrams.flow(spec)`，声明泳道 `lanes`、节点 `nodes` 与有向连接 `edges`。
2. **泳道底色交替分界**：垂直或水平泳道背景采用极淡的纸白 `WASH` 与纯白 `PAPER` 或冷纸白 `WASH_COOL` 交替铺底，泳道间使用 `GREY_LIGHT` 细线分割。
3. **正交折线连接流向**：跨泳道或拐弯连接必须采用严格的水平与垂直正交折线，拐角处直角连接。
4. **回流与循环特殊标注**：向上的反馈回流线必须避让模块中心，避免穿透正在执行的中间模块。

---

## 4. 禁止做

1. **严禁箭头无序对角穿插**：严禁斜穿大半个屏幕直刺目标模块。
2. **严禁分支引线无标注**：判定框延伸出的两条箭头绝对禁止不标注判定结果。
3. **严禁粗重黑色大箭头**：严禁使用 Word/PowerPoint 风格的粗体三角形实心大剪头。

---

## 5. 推荐 API 规范

```python
import academic_fig as afg
import academic_fig.diagrams as d

afg.apply_theme()

# Spec 驱动流程图定义（键名真实存在于 academic_fig.diagrams.flow）
spec = {
    "title": "控制协同流程",
    "lanes": ["规划层", "控制层"],
    "nodes": [
        {"id": "gen", "label": "生成路径", "lane": 0, "col": 0},
        {"id": "track", "label": "轨迹跟踪", "lane": 1, "col": 0, "highlight": True}
    ],
    "edges": [
        {"from": "gen", "to": "track", "label": "期望轨迹"}
    ],
    "footnote": "流程说明：虚线划分规划层与控制层泳道；高亮模块为核心跟踪器。"
}

ax = d.flow(spec, width="double")
afg.save(ax.figure, "out/fig_diagram_flow")
```

### 降级备选（仅在极特殊定制需要逃生时）
仅当标准 `afg.diagrams.flow` 的泳道正交排版完全无法表达极特殊的拓扑时，才退到手绘。手绘时禁止手搓阴影，并统一使用 `afg.palette`。
