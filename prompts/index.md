# 学术论文插图提示词库索引 (prompts/index.md)

本提示词库为 `academic-figures` 技能的核心指导规范，旨在指导 AI 助手将用户的制图意图精准翻译为完全遵循极简学术风格（白纸+墨线+低饱和强调色）的 Matplotlib 代码。

---

## 1. 结构概览与导航

提示词库分为全局原则、需求收口、基础系统、大类图表规范、示意图与自检判定六大层次：

| 文件 | 类别 / 层次 | 核心定位与说明 |
|---|---|---|
| `00_system.md` | 全局系统提示词 | 定义核心人格、白纸墨线视觉基准、硬性约束与默认行为 |
| `10_intake.md` | 需求澄清与收口 | 4 步问答漏斗（图型/数据/栏宽/重点）与反发散决策树 |
| `20_palette_typography.md` | 色板与排版规范 | 冻结色板权威色值、语义绑定、字体层级、线宽与坐标轴规范 |
| `30_cat_compare.md` | 大类1：比较与组成 | 柱状/分组/堆叠/百分比堆叠/点图/棒棒糖/坡度/哑铃/瀑布/帕累托/饼图/环形/华夫/树图/旭日 |
| `30_cat_trend.md` | 大类2：趋势与时序 | 折线/多折线/面积/堆叠面积/阶梯/带状置信区间/事件图/甘特图 |

| `30_cat_relation.md` | 大类4：关系与回归 | 散点/回归散点/气泡/2D直方/Hexbin/等高线/相关矩阵/残差/Q-Q |

| `30_cat_spatial.md` | 大类11：空间与连续场 | 散点地图/设色地图/空间热力/填色等高线/矢量场Quiver/流线/3D曲面/三元相图 |
