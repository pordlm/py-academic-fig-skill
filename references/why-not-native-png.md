# 为什么不让 AI 直接出 PNG（why-not-native-png）

用户最常见的诉求是：「我给你这段描述/这张截图，你直接给我一张论文用的图。」
这件事听起来更快，实际上**更慢**，而且交付物一定被退回。这篇说明原因和替代路径。

---

## 1. 五个硬伤

### ① 改不动

图一旦是位图，任何一处改动——把「对照组」改成「对照」、坐标上限从 60 调到 70、
图例挪个位置——都要整张重画。实际写作中，一张图在投稿周期里平均要改 **6–10 次**
（审稿意见、单位换算、配色调整、增删序列）。位图每一次都是重新生成 + 重新对版。

**代码生成**：改一行数据或一个参数，重跑 3 秒，PNG+PDF 一起更新。

### ② 数字对不上

AI 画图是"画得像"，不是"按数据画"。柱高 41.2 还是 43.1 全凭它高兴；
误差棒的长度、p 值的位置、AUC 的数值，都可能与你的结果文件无关。
而论文图的**首要属性是数值可追溯**。

**代码生成**：数据从 CSV/JSON 读，图上每个数字都能回溯到源文件；
`check` 会核对尺寸、配色、字号，图注强制写来源与口径。

### ③ 分辨率与矢量

期刊要求 300 dpi 以上、线稿要矢量（PDF/EPS/SVG）。
生成式图像的"高清"是插值出来的假细节，不是真实的几何边缘；
放进 PDF 后缩放会糊，字体也不是嵌入字体而是像素。

**代码生成**：`save()` 默认 300 dpi PNG + Type 42 字体嵌入的 PDF，可无损放大。

### ④ 中文字形

生成式模型画中文标签经常出现：字少一笔、两个字粘在一起、标点方向错、
英文与汉字基线不齐。这类问题在 300 dpi 打印稿上非常显眼，而且**无法局部修**。

**代码生成**：字形由系统字体渲染，`typography.text_safety()` 提前拦住
"中文 + `$…$` 混排"这个方框高发区。

### ⑤ 不可复现、不可审计

半年后要补一张同风格的图、或者审稿人要求"换一组数据重画"，位图方案只能从头再来，
而且**必然画不出同一张**（同一段提示词每次结果都不同）。团队协作时更糟：
没人知道那张图是怎么来的。

**代码生成**：脚本 + 数据 = 图。进版本库，可 review、可 diff、可复跑。

## 2. 那截图/位图在什么时候仍然合理

| 场景 | 做法 |
|---|---|
| 显微镜、电镜、卫星、CT 等**原始影像** | 位图是数据本身，直接用；标注用 `afg` 画在矢量层再导出 |
| 软件界面截图（流程图里的 UI） | 保留位图，但裁边对齐、加 0.8 pt 细框，与矢量图同一套留白 |
| 已有论文里要复用的**示意图**（有版权） | 需授权；能重画就重画（重画的风格才统一） |
| 临时讨论用草图 | 随便；但别进最终稿 |

判断标准一句话：**这张图里有没有"必须与数值一致"的元素？**
有 → 必须代码生成；没有（纯影像）→ 位图可以，但要按上面的方式嵌进矢量排版。

## 3. 正确的工作流（三步）

```
① 说清结论  →  ② 选图型/给数据  →  ③ 代码生成 + 自检
```

1. **结论先行**：一句话写清"这张图要让读者看到什么"。没有这句话就不要开始画。
2. **给数据或给结构**：数据图给 CSV/数组（n、均值、误差含义）；示意图给层级/流程结构。
3. **生成 + 自检**：

```bash
python make_figs.py                                  # 一条命令出全套 PNG+PDF
python -m academic_fig.cli check --dir examples/out --strict   # 尺寸/配色/字体/命名全面体检
```

## 4. 如果你手上只有"一张参考图"

这恰恰是本框架最擅长的场景：不是"复刻那张图的像素"，而是**提取它的版式规则**——
白底、细框、刻度朝内、低饱和强调色、充足留白、图注在下。然后：

```python
afg.apply_theme()                    # 把规则变成 rcParams
fig, ax = afg.paper_fig("single")    # 版心宽度对上期刊
afg.plots.bar(ax, …)                 # 用同一套语义色画你的数据
afg.footnote(fig, "数据来源：…；口径：…")
afg.save(fig, "fig01_x")
```

出来的是**你的数据**、**参考图的风格**、**可改的源码**。三者兼得，
这正是"直接生成一张 PNG"永远给不了的东西。

## 5. 一句话总结

> 论文图不是"图像"，是**可复现的结果表达**。
> 位图能表达形状，表达不了"这个数从哪来、怎么改、怎么审"。
